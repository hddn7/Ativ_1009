# Portfólio | Sistemas de Informação

Portfólio pessoal criado com React, Vite e CSS. O conteúdo está em português e destaca estudos, tecnologias e projetos acadêmicos relacionados ao curso de Sistemas de Informação da UMC.

## Executar localmente

```bash
npm install
npm run dev
```

## Personalização

Edite `src/App.jsx` para atualizar nome, apresentação, links e projetos com seus dados reais antes de publicar.

## Publicação

O projeto está pronto para deploy na Vercel como aplicação Vite. Configure o diretório raiz como `.`; o comando de build é `npm run build` e a saída é `dist`.
